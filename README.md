
# Projeto LGPD - Clínica Vida

## Sobre o projeto

Este projeto apresenta um banner de consentimento de cookies
para a Clínica Vida.

O visitante pode escolher entre aceitar todos os cookies,
aceitar apenas os essenciais ou personalizar suas preferências.

As escolhas são armazenadas no navegador por meio de cookies
com validade de um ano.

## Categorias de cookies

- Essenciais: sempre ativos.
- Análise: podem ser ativados ou bloqueados.
- Marketing: podem ser ativados ou bloqueados.

## Cookies utilizados

- consentimento_lgpd
- cat_essenciais
- cat_analise
- cat_marketing

## Como testar

1. Abra o projeto pelo Live Server.
2. Na primeira visita, o banner será exibido.
3. Escolha uma opção de consentimento.
4. Recarregue a página para verificar se a escolha foi salva.
5. Clique em "Reabrir preferências" para alterar as escolhas.
6. Confira os cookies em F12 → Application → Storage → Cookies.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Cookies do navegador
